どちらの案でも共通の処理と表示

  • 1コメントにつき推論は1回：取得 → 言語判定（Chrome 内蔵 API）→ 重複の除去・まとめ処理 → Clef で有害判定 → 小型 LLM で翻訳とカテゴリ分類を同時に実行。結果は保存し、フィルターと要約で使い回します。
  • 日本語のコメントは翻訳を飛ばし、分類だけを行います。
  • カテゴリごとの表示方法：表示 / ハイライト / ぼかす / 隠す。隠したコメントは「非表示 n件」にまとめ、クリックで開けます。
  • 負荷の上限：保持するコメント数に上限を設けた古い順の入れ替え式、画面に見えている範囲だけを処理、流量が多いときは間引き。
